# Arnau Garcia - Creative Portfolio

A high-performance, immersive portfolio built with **React**, **Three.js**, and **Framer Motion**.

![Portfolio Preview](public/preview.png) *(Note: Add a preview image here)*

## ✨ Highlights
- 🎨 **Creative 3D Background**: Interactive abstract geometry and plexus effects.
- ⚡ **Ultra-Fast**: Built with Vite and optimized for 60fps performance.
- 📱 **Fully Responsive**: Seamless experience across mobile, tablet, and desktop.
- 🖱️ **Custom Interactions**: Specialized cursor logic and "decrypting" text effects.

## 🛠️ Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
